A folder. A double-click. A CSV.

Windows setup for a repeatable local workflow.

Download the package
  1. Set up onceExtract the ZIP. Install Python 3.12+ with “Add Python to PATH”, then double-click setup.cmd.
  2. Add invoicesPlace PDFs in inputs. The package includes ten fictional PDFs for an immediate first run.
  3. Run and reviewDouble-click run.cmd. Open output/invoices.csv and the review page. Originals stay unchanged.
  4. Use AI for other layoutsSet OPENAI_API_KEY and OPENAI_MODEL, then run run_ai.cmd. This mode sends PDFs to OpenAI and may incur API charges. Live AI extraction requires validation with your account and documents.

What the review checks

Printed line amounts against quantity × unit price; line totals plus tax and shipping, less discounts, against the printed invoice total. Missing fields, unreadable scans and duplicate invoice identifiers remain visible for manual review. Tolerance: 0.01 per invoice and line.

The six reconciled samples demonstrate the supported layouts. The remaining four demonstrate total differences, incorrect line calculations, missing dates and image-only PDFs. Unknown layouts require tailored extraction rules or the configured AI mode. Word extraction is outside this PDF-focused package.
