A folder. A double-click. A detailed CSV.

The Python package uses the same five layout profiles and preserves fields that are missing or uncertain for review.

Set up onceInstall Python 3.12+ with “Add Python to PATH”. Extract the ZIP and double-click setup.cmd.
  • Place PDFs in inputsThe package includes these five publisher documents. Move them out before adding your own batch.
  • Run and reviewDouble-click run.cmd. Open the CSV and review page in output.
  • Other layoutsUse tailored rules or the optional AI launcher. AI requires your API configuration and validation against your documents; it is not used by this browser demo.

    • Sources and extraction scope

    These are downloaded public examples, not past client invoices. Four copies replace contact/payment details; the Northwind example already contains fictional test data. Their layouts and financial values are preserved. The local extractor supports these five profiles and the legacy test layouts; unfamiliar PDFs require additional rules or validated AI extraction. Image-only scans require OCR or AI vision.
